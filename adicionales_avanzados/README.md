### Material avanzado no evaluado

Esta carpeta conserva el material del diseño anterior.

#### Estructuras incluidas

- Fenwick Tree,
- Segment Tree,
- Lazy Propagation,
- Sparse Table,
- Suffix Array,
- B-Tree.

Estos archivos no forman parte del calendario obligatorio, de los controles, de las prácticas calificadas ni de los exámenes del curso simplificado.

El material se mantiene como referencia para cursos posteriores o para ampliación voluntaria.

#### Algoritmos de texto

La subcarpeta `algoritmos_texto/` contiene:

- Circular Suffix Array,
- Burrows-Wheeler,
- Move-to-Front.

Estos ejemplos se reservan para cursos de algoritmos de texto o compresión de datos.
